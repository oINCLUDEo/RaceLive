# apps/admin — панель модерации и контента (Фаза 5)

Заглушка. Реализуется в Фазе 5. Next.js.

- Модерация чата из интерфейса: мьют, удаление сообщений (не из базы).
- Управление стримами: мгновенное отключение (`streams.is_active`, эффект <5 c).
- Контент: RU-названия этапов/трасс/пилотов, сообщения рейс-контроля.

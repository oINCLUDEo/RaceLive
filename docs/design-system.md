# Дизайн-система «Оксид»

Задача — не «красиво», а «выглядит дороже, чем стоило». Дорогое впечатление создают
типографика, дисциплина плотности и одна запоминающаяся деталь. Не эффекты.

Не берём тренды-однодневки: бенто-сетки, стеклянные панели, градиентные размытия, аврора-фоны,
неоновый киберпанк. Живёт долго: сильная типографика, честная плотность данных, цвет со смыслом.

Реализация токенов — в `apps/web/app/globals.css` и `apps/web/tailwind.config.ts`.

## Два правила, из которых выводится всё

1. **Цвет живёт в данных, а не в интерфейсе.** Фиолетовый = лучшее время сессии, зелёный =
   личный лучший, жёлтый = медленнее, красный = флаг/сход, синий = синий флаг/круг отставания.
   Перекрашивать под брендинг нельзя.
2. **У интерфейса нет цветного акцента.** Кнопки, ссылки, активные состояния — светлые, цвета
   кости. Настроение задаёт подложка (бордовый «оксид»), а не акцент. Красный оставлен красному
   флагу.

## Палитра (OKLCH — источник правды, hex — результат)

```css
--surface-0: oklch(0.16 0.022 18);  /* #170D10 страница */
--surface-1: oklch(0.21 0.020 18);  /* #241518 панели, таблицы */
--surface-2: oklch(0.26 0.018 18);  /* #2F1C20 всплывающие слои */
--line:      oklch(0.32 0.016 18);  /* #3A2226 волосяные линии */
--bone:      oklch(0.93 0.006 40);  /* #EDE6E4 текст, кнопки, ссылки */
--mute:      oklch(0.62 0.012 20);  /* #9C8286 вторичный текст */
--disabled:  oklch(0.45 0.014 20);

/* функциональные — только в данных, менять нельзя */
--purple: #B04CE6;  --green: #4FD87A;  --yellow: #E8C13A;
--red:    #E5484D;  --blue:  #3E8FE0;
```

Правила: насыщенность только в данных (хрома поверхностей <0.025); чистого чёрного нет нигде;
брендового акцента не существует; пять функциональных цветов — только в данных. Контраст:
`--bone` на `--surface-0` ≈13:1, `--mute` на `--surface-1` ≈5:1 (AA с запасом). Светлая тема —
второй приоритет (гонки смотрят вечером).

## Типографика

- **Geologica** — заголовки, крупные числа, названия сессий.
- **Golos Text** — интерфейс и текст.
- Таблицы: `font-variant-numeric: tabular-nums` обязательно (цифры не прыгают при обновлении).

Шкала: Display 64/1.00 (Geologica 600, трекинг −0.03em) · H1 40/1.10 · H2 28/1.20 · H3 20/1.30
(Golos 600) · Body 16/1.55 (строка ≤72 знака) · Small 14/1.45 · Data 15/1.20 (tabular) ·
Micro 12/1.30.

## Плотность и структура

- **Зона данных** (таблицы, тайминг, графики): плотно, без карточек/теней/скруглений,
  разделение волосяными линиями `--line` 1px, ритм 4px.
- **Зона повествования** (новости, трассы, маркетинг): просторно, ритм 8px, строка ≤72 знака.
- Скругления кодируют иерархию: `0` — таблицы/панели данных, `4px` — кнопки/поля, `8px` —
  модалки/тосты. Теней нет, кроме всплывающих слоёв; слои разделяются яркостью поверхности.

## Движение

Один осмысленный момент: **смена позиции в таблице** — строка переезжает за 240 мс, фон коротко
вспыхивает до `--surface-2`, появляется стрелка направления. Подсветка яркостью, не цветом
(зелёный/жёлтый заняты смыслом). Остальное 150–200 мс, easing `cubic-bezier(0.2,0,0,1)`.
Никаких fade-and-slide-up на скролле. `prefers-reduced-motion` уважается везде.

## Мобильный — приоритетный

Тайминг смотрят с телефона рядом с ТВ. Десктоп — адаптация мобильного. В таблице колонки:
позиция, код пилота, интервал, шина; остальное по раскрытию строки. Шрифт в таблице ≥15px,
зоны нажатия ≥44px.

## Планка качества (без исключений)

Адаптивность до 360px, видимый фокус с клавиатуры, контраст текста ≥4.5:1,
`prefers-reduced-motion`, семантические таблицы, OG-картинки под каждый этап, LCP <2 c на 4G.

## Тон текста

Активный залог, обычный регистр, без канцелярита. Кнопка называет действие («Открыть тайминг»,
не «Подробнее»). Одно действие — одно название по всему продукту. Ошибка объясняет, что
произошло и что делать. Пустой экран — приглашение к действию.

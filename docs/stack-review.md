# Разбор стека

Итог: стек внутренне согласован и для масштаба 5–10k одновременных зрителей правильный, без
оверинжиниринга. Принят с четырьмя оговорками (см. ADR-003…006 в [decisions.md](decisions.md)).

## Выбрано верно — не трогать

- **uPlot** для телеметрии. Recharts/Chart.js на потоке 4 Гц × 20 машин лягут; uPlot рисует
  сотни тысяч точек без потери кадров.
- **Centrifugo** вместо самописного WS. Каналы, presence, history, JWT, Redis-фанаут из коробки.
- **Postgres + TimescaleDB** в одной базе. Компрессия гипертаблиц ~10–20× на телеметрии;
  за сезон это единицы гигабайт.
- **FastAPI + pandas + FastF1** в одной экосистеме — меньше швов.
- **Разделение ingest (вне РФ) и пользовательской БД (в РФ)** — грамотная реализация 152-ФЗ.

## Оговорки (приняты как ADR)

1. **Сайзинг БД (ADR-003).** 4 vCPU / 8 ГБ под API+Postgres+Timescale+Redis одновременно — на
   грани. Timescale любит RAM; во время live добавляется burst-запись ingest. → Postgres на
   отдельный узел или ≥16 ГБ RAM. Live-*чтение* идёт из Redis/Centrifugo, а не из Postgres, так
   что пик держится, но узел БД «прижмёт» первым.
2. **pandas не в request-path (ADR-005).**
3. **ARQ, не Celery (ADR-004).**
4. **Автоген contracts из OpenAPI (ADR-006).**

## Профиль нагрузки

- Между этапами почти всё — статика с CDN (ISR).
- Пик предсказуем с точностью до минуты → доп. воркеры по расписанию, не по метрикам.
- Одна нода Centrifugo держит десятки тысяч соединений; до 5–10k масштабирование не нужно.
- Главный риск — не нагрузка, а падение источника посреди гонки. Обрабатывается деградацией
  (Фаза 3): последнее известное состояние + честная пометка + таймер.

## Стоимость (ориентир, ₽/мес)

| Позиция | В месяц |
|---|---|
| VPS под API (4 vCPU, 8 ГБ) | 1 500–2 500 |
| VPS под БД (отдельно, ≥16 ГБ) — по ADR-003 | по тарифу |
| VPS под ingest, вне РФ (2 vCPU) | 800–1 500 |
| VPS под Centrifugo (2 vCPU) | 800–1 500 |
| Объектное хранилище и CDN | 300–1 000 |
| Домен, почта, Sentry | 500 |

Видео сюда не входит — у него отдельный бюджет (см. [video-strategy.md](video-strategy.md)).
Основная статья расходов — время, а не серверы.

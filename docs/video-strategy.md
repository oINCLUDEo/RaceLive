# Стратегия по видео

Решение зафиксировано в ADR-007. Здесь — детали и цифры.

## Главный принцип

Видеохостинг из основного стека **не следует**. FastAPI, Postgres, Timescale, Centrifugo, Redis
не имеют к видео отношения. Видео — это отдельный конвейер и **отдельный сервис** (`/apps/video`),
живущий рядом со своим бюджетом и своим CDN.

## Две разные задачи

**Стильный плеер — легко, на этом же стеке.** `hls.js` + свой UI на Next.js/Tailwind в стиле
«Оксид». Внешне можно сделать плеер дороже Twitch. Это фронтенд.

**Оптимизированный (дешёвый) хостинг — стек не при чём.** Конвейер:

```
загрузка/RTMP → транскодинг (ffmpeg, 3–5 рендиций ABR) → упаковка HLS/DASH →
объектное хранилище → CDN → плеер
```

## Где ломается «оптимизировано» — две цифры

1. **CDN-egress.** Гонка 2 ч, 1000 зрителей, 720p ≈ 3 Мбит/с → **~2.7 ТБ за одну гонку**.
   Этапов 24. Egress, а не серверы, — главная статья. Вся прочая инфра — 4–7 тыс ₽/мес; видео
   съест это на порядки.
2. **Live-транскодинг.** Живые стримы = RTMP-ingest + транскодинг в реальном времени + низкая
   задержка (LL-HLS/WebRTC) = постоянно занятый CPU/GPU весь уик-энд. VOD (записи) на порядок проще.

## Дорожная карта видео (по возрастанию сложности)

| Этап | Что | Как |
|---|---|---|
| Сейчас (Фаза 6) | **Embed** сторонних стримов | Twitch/VK Video/YouTube iframe + **регулятор смещения звука**. Ноль видеохранилища. Это и есть настоящая фича. |
| Позже | **VOD** (записи после гонки) | Своими силами: ffmpeg-воркер + объектное хранилище + CDN. Отдельный сервис `/apps/video`, основной стек не трогается. |
| Ещё позже | **Live** собственный | **Не строить пайплайн самим.** Управляемый сервис: Kinescope или VK Video (РФ), Mux/api.video (зарубеж). Платим за готовый конвейер, поверх — свой плеер и UI. |

## Регулятор смещения звука

Фича, которой нет у других: зритель смотрит картинку из одного источника, слушает кастера из
другого — они разъезжаются. Ползунок задержки (−5…+5 c) выравнивает одним движением. Значение
сохраняется локально **по каждой платформе отдельно**. Требует только фронтенда.

## Вывод одной строкой

Стильный плеер — да, на этом стеке; дешёвый собственный live-хостинг — нет, и стек не поможет;
на старте embed + регулятор смещения сильнее собственного видео.

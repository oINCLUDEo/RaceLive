# CLAUDE.md

Ориентир для будущих сессий. Держи этот файл коротким; детали — в `docs/`.

## Что за проект

Портал живого тайминга / результатов / телеметрии автогонок с русской локализацией.
Ценность продукта — русские имена, трассы и **сообщения рейс-контроля**, живущие в схеме БД, а не в файле переводов на фронте. Название и домен ещё не выбраны.

## Текущее состояние

- Реализуется **Фаза 1: Расписание**. Остальное — заглушки/документация.
- Провайдер MVP — **Jolpica** (бесплатный, без ключа), для расписания и результатов. OpenF1 (коммерческий) подключается в Фазе 3 для live.

## Твёрдые правила (не нарушать без явного согласия пользователя)

- **Публичный API не отдаёт сырые объекты провайдера.** Только сериализаторы/агрегаты. См. `apps/api/app/schemas.py`.
- **Клиент провайдера всегда за token-bucket'ом** с backoff. Лимит не должен превышаться физически.
- **pandas не вызывается в request-path** REST. Тяжёлые расчёты — только в post-session воркере.
- **Русская локализация — в схеме БД** (`name_ru`, `message_ru`), не на фронте.
- **Дизайн: цвет живёт только в данных.** Интерфейс без цветного акцента, кнопки цвета кости. Пять функциональных цветов (фиолетовый/зелёный/жёлтый/красный/синий) — только в таблицах данных. См. [docs/design-system.md](docs/design-system.md).
- **Видео — всегда отдельный сервис**, не часть основного стека. См. [docs/video-strategy.md](docs/video-strategy.md).

## Стек (кратко)

Next.js (App Router, TS, Tailwind) · FastAPI (Python) · PostgreSQL 16 + TimescaleDB · Redis · Centrifugo (Фаза 3) · uPlot (Фаза 4) · Docker Compose. Фоновые задачи — **ARQ** (решено, не Celery).

## Как запустить

```bash
cp .env.example .env && docker compose up --build
```
web → :3000, api → :8000/docs.
